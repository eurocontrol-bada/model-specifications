This repository hosts the BADA Model Specification documents per model family.

The BADA model specifications are licenced under the EUPL-1.2 licence, with certain exceptions described in the AMENDMENT_TO_EUPL_license.md file, reflecting EUROCONTROL's status as an international organisation.

**Note regarding a commercial Use of Tools Implementing the BADA Model Specifications.**

Any entity intending to commercialize a software tool or application incorporating the BADA (Base of Aircraft Data) model specifications is strongly advised to initiate prior consultation with the EUROCONTROL BADA Support Team (eih.bada@eurocontrol.int) in order to verify the conformity of the intended application domain with the terms and conditions of the BADA licensing policy.

This consultation serves to ensure that prospective end users of the tool may be deemed eligible for the granting of a BADA Licence Agreement, which governs the authorized use of BADA datasets.

Please note that compliance of the tool’s application domain with EUROCONTROL’s licensing framework constitutes a mandatory prerequisite for the issuance of a BADA Licence Agreement. Non-compliance may result in the rejection of licensing requests or the imposition of additional legal or technical restrictions.
